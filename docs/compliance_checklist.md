# GPT Image 2 生图字段捷径合规自检

## 基本信息

- 插件名称：GPT Image 2 生图
- 插件类型：字段捷径插件，FaaS 版
- 结果类型：附件
- 外部服务：APIMart GPT Image 2 API
- 请求域名：`api.apimart.ai`

## 数据处理说明

- 插件读取用户在字段配置中提供的提示词。
- 插件可读取用户选择的附件字段中的参考图片临时链接。
- 插件将提示词、可选参考图片和图片尺寸等参数发送至 APIMart 图像生成接口。
- 插件不会在本地持久化用户数据。
- 插件返回 APIMart 生成的图片 URL，并作为飞书附件字段结果返回。

## 权限与授权

- 插件使用 Header Bearer Token 方式配置 APIMart API Key。
- API Key 由用户自行提供，用于调用 APIMart 接口。
- 插件不请求额外飞书 OAuth 权限。

## 网络与安全

- 已配置域名白名单：`api.apimart.ai`
- 构建产物不包含真实 API Key。
- 本地调试配置中的 `YOUR_APIMART_API_KEY` 仅为占位符。

## 内容安全提示

- 用户应确保输入提示词和参考图片拥有合法使用权。
- 用户应避免生成或上传违反平台规则、侵犯第三方权益或包含敏感个人信息的内容。
- 生成内容由外部图像生成服务返回，建议在业务发布前进行人工审核。

## 自检结论

当前代码包已通过本地模拟测试、构建和打包验证，可提交飞书多维表格字段捷径审核。上线前建议由开发者补充正式模板链接、用户群链接和说明文档在线链接。
